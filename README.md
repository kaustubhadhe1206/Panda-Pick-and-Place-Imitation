# CSCI 645 HW2: Imitation Learning for Robot Pick-and-Place

**Task:** pick-and-place with a Franka Panda. The robot picks a cube up from the table, swings its arm
**45–60° around its base** (seen from the top), puts the cube down on a target spot, and lets go. The
environment is MuJoCo Playground's `PandaPickCube` (JAX/MJX backend, state observations) with only the
cube/target layout and the episode length changed (see *Environment* below).
**Teacher:** scripted pick-and-place expert (IK + gravity-compensated joint targets).
**Student:** Diffusion Policy (state-based, 1-D temporal conditional U-Net, DDPM).
**Experiment (Option A):** dataset quantity, 25 vs 50 vs 100 demonstrations (nested subsets), 3 training seeds each.

The report is `report.pdf`. This README explains how to reproduce every number and figure in it.

See `results/summary_table.md` (generated by `code/analyze.py`) and the figures in `results/`.

## How to reproduce

All steps run on **one** GPU platform per sweep (Colab or CARC). Every script takes
`--set key=value` overrides on top of its YAML config.

### Option 1: Google Colab (T4)
Open `notebooks/run_pipeline.ipynb` and run the cells in order. The notebook clones this repo,
installs `requirements.txt`, and runs the pipeline below. Every output (checkpoints, data, results,
videos, logs) is saved to `My Drive/CSCI-645 Homework 2/pick-and-place-swing/`. Interrupted training
continues from its last saved step.

## Design details

**Environment.** A subclass of Playground's `PandaPickCube` (`code/hw2/envs.py`). Unchanged from
PandaPickCube: robot, cube, physics, control step 0.02 s (4 physics substeps of 0.005 s), observations
and actions. **Changed:**
- **Layout:** the cube start and the target spot are both on the table. They are placed around the
  robot base, which sits at the origin; positions below are seen from the top:
  - both spots are within 60° left or right of straight ahead (+x),
  - both are 0.40–0.60 m from the base, a comfortable reach for a top-down grasp (the Panda's maximum
    reach is about 0.85 m),
  - the angle between them is **45–60°** in a random direction, so the arm swings well across the
    workspace and the spots end up 0.31–0.60 m apart.

  The sampler is `pick_and_place_from_uniforms`, and these limits are unit-tested.
- **Episode length:** 250 steps (5 s) instead of 150, because carrying, placing and releasing take
  longer than lifting.
- **First observation:** after `reset()` we run `mjx.forward`. Upstream `reset()` skips this step,
  so the gripper and cube positions in the first observation would otherwise all be 0. It does not
  change the physics.

Each episode is reset from `jax.random.PRNGKey(seed)`.

**Observation (66-D, from the env).**
- qpos (16): 7 arm joints, 2 fingers, the cube's free joint
- qvel (15)
- gripper position (3) and gripper rotation (6)
- cube rotation (6)
- cube minus gripper (3)
- target minus cube (3)
- target-cube rotation difference (6)
- ctrl minus qpos (8)

**Action (8-D in [-1, 1]).** The action changes the actuator position targets:
ctrl <- clip(ctrl + 0.04 * a). That covers 7 arm joint targets (rad) and 1 finger-opening target (m).

**Success** (defined before running any experiment), checked at the **final** step:
- the cube centre is within **3 cm** of the target spot, which means it is resting on the table there,
- the gripper has **let go** (finger opening > 3 cm),
- the cube never went out of bounds.

`results/fig_success_vs_threshold.png` also reports success at 2, 3, 5 and 10 cm.

**Failure labels.** Each failed episode gets one label:
- never reached the cube
- grasp failed (cube never lifted)
- still holding (never put down)
- not released (on target, gripper still closed)
- misplaced (put down or dropped away from the target)
- out of bounds

**Teacher.** A phase machine: approach, descend, grasp, lift, carry, lower, release, retreat.
- A Cartesian reference point moves toward each waypoint with a speed limit.
- Damped least-squares IK (gripper position + pointing down, with a gentle pull toward the home pose) gives the joint targets.
- A gravity feedforward `g(q)/kp` is added, because the model's position servos sag under gravity.
- If the cube slips, the teacher grasps it again.

All attempts are stored with labels; training uses the successful ones, and that filtering is reported.

**Student.** Diffusion Policy, adapted from Chi et al.'s official state-based notebook.
- Network: ConditionalUnet1D with widths 128/256/512, FiLM-conditioned on the 2 most recent observations.
- Plans 16 actions at a time and executes 8 before replanning.
- Noise: 100-step DDPM with the squaredcos_cap_v2 schedule; the network predicts the noise.
- Optimizer: AdamW with lr 1e-4 and weight decay 1e-6, 500 warmup steps, then cosine decay.
- EMA weights (power 0.75), batch size 256.
- 20k gradient steps for **every** dataset size.
- Every observation and action dimension is min-max normalized to [-1, 1], using the training subset only.

**Seeds.**
- Demonstrations: env seeds 0, 1, 2, …; the n-demo subset is the first n successes in seed order, so the subsets are nested.
- Evaluation: env seeds 100000–100099 (100 held-out starts), the same for every condition and for the teacher.
- Training seeds: 0, 1, 2.

**Provenance.** Every JSON in `results/` contains `system_info` (Python, GPU, package versions,
git commit), and every run directory contains its fully resolved `config.yaml`.
